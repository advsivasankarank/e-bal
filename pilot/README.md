# e-BAL Pilot Validation

This directory contains the validation toolkit for the e-BAL pilot deployment.

## Files

| File | Purpose |
|---|---|
| `PILOT_VALIDATION_REGISTER.md` | Master tracking sheet for all 11 pilot entities |
| `DEFECT_LOG.md` | Log for capturing and tracking defects found during pilot |
| `PRODUCTION_READINESS.md` | Updated readiness score, success criteria, and Go/No-Go framework |

## Validation Protocol

1. **Import TB** via Smart Bridge or XML Import
2. **Map ledgers** using Mapping Workbench
3. **Generate report** via Reports page
4. **Export** PDF, XLSX, DOCX
5. **Compare** against manually prepared accounts
6. **Record** findings in the register and defect log
7. **Decide** Go / No-Go based on success criteria
